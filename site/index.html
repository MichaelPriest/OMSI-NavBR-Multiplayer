Estado da Alpha.11

Test 2 pronta para validação da comunidade.

A Alpha.11 reúne correções de HUD e telemetria com uma camada experimental de integração física. Recursos marcados como experimentais ainda não são considerados estáveis.

PRONTO PARA TESTAR

HUD e navegação

HUD mais compacto/transparente, velocidade corrigida e visibilidade ligada à janela real de gameplay.

  • Groundspeed + fallback linear
  • HUD some em menus/opções
  • Próxima parada destacada
  • Rota completa
PRONTO PARA TESTAR

Paradas da linha ativa

Com viagem ativa, o NavBR mostra somente as paradas daquela rota. Sem rota, pode mostrar todas as paradas válidas.

  • Leitura de .ttp
  • Fallback pela geometria
  • Menos poluição no minimapa
  • Próxima parada preservada
EXPERIMENTAL

Ônibus remoto físico 3D

Primeira rodada pública de spawn, atualização e remoção de ônibus remotos através do plugin x86.

  • Opt-in explícito
  • Mesmo mapa/build
  • Mesmo ônibus instalado localmente
  • Testar inicialmente com poucos jogadores

Alpha.11 • integração profunda

Ônibus remoto físico 3D — experimental.

A Test 2 abre o primeiro teste público da camada física. Não é um recurso estável e pode falhar com determinados mapas ou add-ons.

Pré-release comunitária

v0.3.0-alpha.11-test.2

Para testar o 3D, use OMSI 2.3.004, instale o plugin pelo NavBR, entre no mesmo mapa/build e tenha localmente o mesmo modelo de ônibus do jogador remoto. O NavBR não distribui conteúdo pago/proprietário.

Abrir Test 2Checklist de teste

Plugin Native AOT x86

Carregado pelo OMSI e conectado ao cliente por Named Pipe local.

Interop C++ x86

Camada isolada para o ABI Borland/Delphi do OMSI 2.3.004.

Proteções

Registro de instâncias próprias, validação de ponteiros e execução no callback/thread do OMSI.

Diagnóstico automático opcional.

×

Chat, áudio/voz, senha, token, arquivos pessoais ou nome do usuário do Windows.
