Sala multiplayer

Dois cliques para hospedar. Uma porta para liberar.

O NavBR inicia um host ASP.NET Core + SignalR dentro do PC do criador da sala.

01

Abra o Multiplayer

Escolha nome, sala, chat e PTT. O HUD acompanha a janela do OMSI.

02

Permita TCP 27730

O cliente pode criar a regra de entrada do Windows Firewall no perfil Privado mediante confirmação UAC.

03

Compartilhe o convite

Em LAN, use o endereço mostrado pelo NavBR. Pela Internet, o roteador/NAT ainda pode exigir encaminhamento de porta.

Dúvidas rápidas

Perguntas frequentes

Preciso ter a Steam aberta?

Não. O NavBR não depende da Steam API e detecta diretamente o processo Omsi.exe.

Quem hospeda a sala?

Por padrão, o PC de quem cria a sala. O servidor dedicado é uma alternativa para quem preferir hospedar separadamente.

Preciso liberar o Firewall?

Para receber conexões de outros PCs, sim. O NavBR oferece uma ação para permitir TCP 27730 no perfil Privado do Windows Firewall. Acesso pela Internet pode exigir também encaminhamento da porta no roteador.

Quais são os atalhos?

Os padrões são F9 para chat e F10 para push-to-talk. Na versão em desenvolvimento eles podem ser alterados para combinações de F9/F10 com Shift/Ctrl, sempre com verificação do keyboard.cfg.

O HUD copia GTA?

Não. A organização usa referências gerais comuns a jogos de mundo aberto, mas os assets, layout e identidade são próprios do NavBR.

Já está totalmente validado dentro do OMSI?

Não. O projeto está em alpha e funcionalidades de runtime continuam exigindo testes reais no OMSI 2.3.004.
