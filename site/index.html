O que o NavBR está construindo

Recursos

01

Telemetria ao vivo

Posição, heading, velocidade, mapa carregado e dados do OMSI em tempo real.

02

GPS e roadmap

Roadmap do próprio OMSI, marcador do ônibus, zoom, pan, follow bus e orientação pelo heading.

03

Multiplayer

Salas online, jogadores no mapa, telemetria compartilhada e evolução futura para sincronização avançada.

04

Sem dependência da Steam

O cliente detecta o Omsi.exe e a pasta real da instalação diretamente pelo processo.

05

Multilíngue

Base preparada para Português (Brasil), English, Español, Deutsch e Français.

06

Atualizações simples

Releases automáticas no GitHub com EXE standalone, pacote ZIP do cliente e servidor.

Informações importantes

Perguntas frequentes

Preciso ter Steam aberta?

Não. O NavBR foi projetado para detectar diretamente o processo Omsi.exe. Ele não depende da Steam API.

O programa já está finalizado?

Não. As versões atuais são alpha e servem para testes durante o desenvolvimento.

O EXE precisa instalar .NET?

O EXE standalone das releases é self-contained e inclui o runtime necessário.

Onde reporto problemas?

Use a área de Issues do repositório no GitHub e informe a versão do NavBR, versão do OMSI, mapa e o comportamento observado.
