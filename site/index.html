Qual arquivo baixar?

Para jogar, baixe só o EXE.

Cliente recomendado — EXE standalone: serve para jogar, entrar em salas e também criar uma sala no próprio PC. Você não precisa baixar o servidor dedicado.

Cliente ZIP: é apenas uma alternativa ao EXE standalone; não é necessário baixar os dois.

Servidor dedicado ZIP: use somente se quiser rodar o servidor separado do cliente, em outra máquina ou processo. Nesse caso, extraia o ZIP e mantenha todos os arquivos juntos.

Carregando releases…

O EXE standalone já inclui o necessário para o uso normal do NavBR. O PC de quem cria a sala funciona como host pela porta TCP 27730. O pacote do servidor é opcional e destinado apenas ao modo dedicado.

Experiência NavBR

Feito para dirigir, não para atrapalhar.

⌖

GPS integrado

Roadmap do próprio mapa, posição, heading, zoom de até 10×, rota ativa, destino e próxima parada.

▣

HUD sobre o OMSI

Minimapa móvel e translúcido, chat visual, atalhos em jogo, contador de jogadores e indicador de voz.

⇄

Peer-host

Quem cria a sala hospeda a sessão no próprio PC. O servidor dedicado continua opcional.

◉

Voz Opus

NAudio + Concentus, 48 kHz mono, frames de 20 ms e push-to-talk configurável.

⌨

Atalhos protegidos

F9/F10 e combinações com Shift/Ctrl são comparadas com o keyboard.cfg real do OMSI.

◎

Sem Steam API

O NavBR detecta Omsi.exe em execução e encontra a instalação diretamente pelo processo.

Sala multiplayer

Dois cliques para hospedar. Uma porta para liberar.

O NavBR inicia um host ASP.NET Core + SignalR dentro do PC do criador da sala.

01

Abra o Multiplayer

Escolha nome, sala, chat e PTT. O HUD acompanha a janela do OMSI.

02

Permita TCP 27730

O cliente pode criar a regra de entrada do Windows Firewall no perfil Privado mediante confirmação UAC.

03

Compartilhe o convite

Em LAN, use o endereço mostrado pelo NavBR. Pela Internet, o roteador/NAT ainda pode exigir encaminhamento de porta.

Transparência de testes

Alpha significa alpha.

O CI valida compilação, cliente x86, EXE standalone e recurso de ícone. O HUD já foi testado em OMSI real para carregamento do roadmap e posicionamento básico. Traçado corrigido da linha, próxima parada, voz, host peer-to-peer e atalhos ainda precisam de validação completa no jogo.
