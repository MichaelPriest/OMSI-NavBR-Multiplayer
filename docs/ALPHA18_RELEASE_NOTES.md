# Alpha.18 — notas da versão / Alpha.18 — release notes

Versão / Version: **v0.3.0-alpha.18**

> **AVISO:** Alpha pública de teste. LAN/local e multiplayer online ainda não foram validados ponta a ponta com dois PCs/duas sessões reais do OMSI.

## Português

- instalador Windows com desinstalador;
- pacote autoral de ícones NavBR;
- verificador de plugin por SHA-256 arquivo a arquivo;
- reparo automático de plugin ausente, parcial ou desatualizado;
- atualização adiada automaticamente enquanto `Omsi.exe` estiver aberto;
- proteção contra sobrescrever arquivos NavBR não rastreados;
- spawn físico reforçado para nunca atribuir o ponteiro do ônibus local a `sim-*`;
- snapshots de `RoadVehicles` antes/depois;
- diagnóstico de visibilidade, ComplObj/model, Kachel e matriz de render;
- falha de movimento do simulador separada da confirmação física.

**Ainda não validado:** sessão real completa em LAN/local, Servidor NavBR online ou Host pela Internet, nem visibilidade/movimento físico remoto consistente entre dois OMSI reais.

## English

Alpha.18 is a public test prerelease. It adds the Windows installer, NavBR icon pack, per-file SHA-256 plugin verification/repair, deferred plugin updates, safer physical-bus pointer ownership and render diagnostics.

**Real end-to-end LAN and online multiplayer with two PCs/two OMSI sessions is still pending.** Physical remote buses and RP remain experimental.
