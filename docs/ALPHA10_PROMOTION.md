# Promoção da alpha.10

A release `v0.3.0-alpha.10` é promovida byte-for-byte a partir dos artefatos permanentes e validados de `v0.3.0-alpha.10-test.6`.

Commit validado da snapshot: `7a0fbe3ffbcc338e776add1e1dec1bb5ac7154ea`.

O workflow de promoção verifica os SHA-256 conhecidos antes de criar a release oficial e recusa sobrescrever uma release existente.
